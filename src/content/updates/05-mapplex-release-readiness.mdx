# Preparing a controlled deployment for broader publication

Mapplex is currently distributed through managed company deployments. Public Play Store publication will follow the current review and correction cycle rather than bypass it.

## Privacy and account controls

The Geova website now provides dedicated privacy and account-deletion pages. Mapplex exposes a discoverable deletion-request path both before and after sign-in. Opening the page does not immediately delete data; it starts a verified request and explains what may be removed or retained.

## Four-language interface coverage

English, Arabic, Spanish, and French now share the same protected translation catalog for primary application workflows. Arabic changes the direction of translated text while the structural layout—navigation, controls, icons, and button locations—stays stable.

Project names, layer names, field names, and collected values are project data. They are never replaced by interface translations.

## Automated release evidence

The release process now includes repeatable checks for:

- Translation-key parity and primary-screen coverage.
- Type consistency and architecture boundaries.
- Source-safety review for dynamic interface rendering.
- Complete regression tests.
- Isolated production builds and bundle budgets.

These checks reduce preventable regressions, but they do not replace Play pre-launch testing, physical-device verification, live service checks, or a review of the Data Safety declaration.
