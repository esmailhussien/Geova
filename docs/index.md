## How Mapplex Works

Mapplex follows a local-first model: supported collection and editing workflows store working data on the device, then synchronize with Geova Cloud when connectivity is available. Prepare offline maps and project data before field deployment; cloud sync, team collaboration, and Geova AI require a connection.
